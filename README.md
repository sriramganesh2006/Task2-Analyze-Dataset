**# Student Performance Dataset Analysis**



**## Project Description**



**This project analyzes the UCI Student Performance Dataset using Python and data analysis techniques.**



**The application provides an interactive dashboard for understanding student data, including dataset structure, statistical information, missing values, duplicate records and student performance.**



**## Objectives**



**- Analyze a real-world student dataset**

**- Understand dataset features**

**- Identify missing values**

**- Identify duplicate records**

**- Calculate descriptive statistics**

**- Analyze student performance**

**- Create data visualizations**

**- Identify relationships between variables**



**## Technologies Used**



**- Python**

**- Pandas**

**- NumPy**

**- Matplotlib**

**- Streamlit**



**## Dataset**



**The project uses the UCI Student Performance Dataset.**



**The main dataset file is:**



**`student-mat.csv`**



**## Features**



**- Dataset overview**

**- Dataset preview**

**- Feature information**

**- Statistical analysis**

**- Missing-value analysis**

**- Duplicate analysis**

**- Final-grade analysis**

**- Grade distribution**

**- Study-time analysis**

**- Absence analysis**

**- Correlation analysis**
